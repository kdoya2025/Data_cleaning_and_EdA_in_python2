🧹 Messy Data Cleaning Project

A practical data cleaning project focused on transforming messy and inconsistent raw data into a clean, structured, and analysis-ready dataset using Python and data analysis libraries.

📌 Project Overview

In real-world analytics, raw datasets are often incomplete, inconsistent, duplicated, or poorly formatted.
This project demonstrates a complete data cleaning workflow used in data analysis projects.

The objective was to:

Detect and handle missing values
Remove duplicates
Standardize inconsistent data
Fix incorrect data types
Prepare the dataset for analysis and visualization

Python
Pandas
NumPy
Jupyter Notebook
Matplotlib
Seaborn
